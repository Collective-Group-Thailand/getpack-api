# getpack — หน้าแรก + ช่วยเหลือและเนื้อหา + ค้นหา + กฎหมาย + 404 · Claude Code Prompt Pack (ลูกค้า รอบ 3)

## วิธีใช้

1. **วางไฟล์:** ทั้งโฟลเดอร์นี้อยู่ที่ `docs/design/home-content-redesign/` ของทั้ง `getpack-web` และ `getpack-api`
2. **ไฟล์ในโฟลเดอร์:**
   - `AUDIT-R3.md` ผลตรวจ 22 route
   - `DECISIONS-R3.md` การตัดสินใจรอบนี้
   - `current/` ภาพหน้าปัจจุบัน
   - `stitch/` งานออกแบบจาก Stitch (ภาพ + HTML ต่อหน้า) ใช้แทน canvas ตามที่เจ้าของสั่ง
3. **หน้าแรกต้องดีกว่าเดิม ไม่ใช่เปลี่ยนใหม่ทั้งหน้า:** เจ้าของชอบหน้าแรกเดิม คงโครงและน้ำเสียงไว้ ปรับเฉพาะที่ระบุใน Phase 1
4. **ลำดับ:** Phase 0 → 1 → 2 → 3 → 4 ทุก Phase หยุดรออนุมัติ
5. **Branch:**
   - Phase 0 ลง `fix/uat-phase0` แล้ว merge เข้า `design/home-content`
   - Phase 1–4 ลง `design/home-content` ที่สร้างจาก `design/liff-signin-share` (ถ้ายังไม่มี ใช้ branch ล่าสุด)
