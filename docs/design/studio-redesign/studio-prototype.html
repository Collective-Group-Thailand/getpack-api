สิ่งที่เจอ

  • มีหน้า "วันนี้อยากเริ่มจากอะไร" สองหน้าที่ข้อมูลไม่ตรงกัน: /studio บอก "122 แบบ" แต่ /studio/new บอก "เลือกจากคลัง 30 แบบ" · "มีไฟล์แบบแล้ว" ใน /studio บอกว่าระบบเช็คความละเอียดแล้วแสดงราคา แต่ใน /studio/new บอกว่า "ข้ามการออกแบบ ไปกำหนดสเปก แล้วให้ทีมตรวจ" · "ลองเล่นกับแบบตัวอย่าง" มีแค่ใน /studio/new
  • หน้าไม่ได้แสดงว่าสตูดิโอทำอะไรได้ ผู้ใช้ครั้งแรกไม่เห็นตัวแก้ไข ฟอนต์ของแบรนด์ หรือไฟล์ .ai ฟรี ก่อนตัดสินใจกด
  • ปุ่ม "เริ่มออกแบบฟรี" ใน header ลิงก์กลับมาหน้าเดิม
  • "สั่งซ้ำจากงานเดิม" แสดงเท่ากับทางอื่นแม้ยังไม่เคยสั่ง
  • "แบบที่คนเริ่มบ่อย" แสดง 3 แบบที่ตรงกับ 3 แบบแรกของคลังแบบกล่อง น่าจะยังไม่ใช่ลำดับตามยอดใช้งานจริง
  • ตัวแนะนำกล่องจากขนาดสินค้าซ่อนอยู่ในหน้าต่างป๊อปอัป ทั้งที่เป็นทางที่ช่วยคนไม่รู้จักชื่อแบบกล่องได้มากที่สุด

สิ่งที่ออกแบบใหม่

  • รวมสองหน้าเป็น /studio หน้าเดียว (/studio/new เปลี่ยนเส้นทางมาที่นี่) ข้อความและจำนวนแบบตรงกันทุกที่
  • Hero แสดงตัวอย่างหน้าจอสตูดิโอ: แผ่นคลี่ + 3D + เครื่องมือ + ราคา (ราคาเบอร์ C ฿50.65 จากหน้าปรับแต่งจริง) · CTA หลัก "เริ่มออกแบบ" รอง "ลองเล่นกับแบบตัวอย่าง"
  • ทางเริ่ม 3 ทางหลัก · "สั่งซ้ำ" แสดงเฉพาะคนที่มีประวัติสั่ง
  • ตัวแนะนำกล่องจากขนาดสินค้าวางในหน้าเลย ไม่ต้องเปิดป๊อปอัป (หน่วย มม./ซม./นิ้ว และการใช้งานตามของเดิม) แนะนำ 3 แบบพร้อมเหตุผลและปุ่มออกแบบ
  • "ทำอะไรได้ในสตูดิโอ" 6 ข้อ · แบบที่คนเริ่มบ่อยเปิดในสตูดิโอได้ทันที · แบบล่าสุดของคุณ (ว่าง → ชวนลองแบบตัวอย่าง)

ข้อมูลจริง: ข้อความและทางเริ่มจาก /studio และ /studio/new หน่วยและการใช้งานในตัวแนะนำ ชื่อแบบกล่อง ราคาเบอร์ C ข้อความทีมช่วยดูแบบร่าง ฟอนต์ของแบรนด์และไฟล์ .ai ฟรี (ตามการตัดสินใจเดิม) · ตัวอย่าง: ผลแนะนำ 3 แบบและเหตุผล ลำดับแบบที่คนเริ่มบ่อย และภาพประกอบ
