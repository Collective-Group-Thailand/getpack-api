สิ่งที่คุณต้องทำ

ก่อน UAT

  1. ให้ CI รัน e2e/integration ของ API บน main (เครื่องที่รันไม่มี Docker)
  2. รัน pnpm db:seed:uat บน UAT พร้อม UAT_SEED_CONFIRM=uat-only และ FIELD_ENCRYPTION_KEY ของ API
  3. รัน Lighthouse บน CI และ k6 บน UAT (เป้า perf ≥ 90, p95 < 300 ms)
  4. ทดสอบบน iPhone และ Android รวมการติดตั้งแอปตามเช็กลิสต์ใน DESIGN-NOTES

ระบบและโดเมน

  1. DNS + TLS agent.getpack.co และตั้ง AGENT_HOST
  2. เพิ่ม agent.getpack.co ใน LINE Login callback และ Firebase authorised domains
  3. VAPID keys จริง และ LINE OA channel
  4. Production API ต้องมี Tesseract ภาษาไทย (Dockerfile แก้แล้ว)

กฎหมาย ภาษี PDPA

  1. ทนายรีวิวสัญญา v2 → วางไฟล์ที่ docs/legal/ → publish ผ่านแอดมิน
  2. เติมข้อมูลบริษัทสำหรับสัญญาและ 50 ทวิ
  3. CPA ยืนยันตาราง SME + ใส่ทุนชำระแล้ว, e-filing +8 วัน, การหักเกินระหว่างปี (แนะนำ: คงแบบไม่คืน)
  4. เพิ่ม ภ.ง.ด.1 ใน tax.calendar
  5. นักบัญชีผูก GL 5 บรรทัดของ P&L
  6. DPO publish consent รายชื่อรอเปิดรับ (แนะนำ: เก็บ 12 เดือน) และยืนยันเก็บรูปนามบัตร 7 วัน

ธุรกิจ

  1. เลือกตัวแทนนำร่อง 10–20 คน ใส่ใน agents.pilot (แนะนำ: pilot 60 วันก่อนเปิด public)
  2. ยืนยันค่าที่ proposed: น้ำหนักคะแนน, 3 วัน, 4 ชั่วโมง, 10/20/40/60% (แนะนำ: ใช้ตาม seed ช่วง pilot)
  3. กันหนี้สูญ (แนะนำ: เริ่ม 1% ลูกค้าเครดิต) และยังไม่ตั้งเพดานยอดอนุมัติ
  4. เปิดสวิตช์จับ lead เมื่อมีเซลล์พร้อม
  5. กรอกผู้ติดต่อเหตุฉุกเฉินใน RUNBOOK §8
